# your health — интернет-магазин витаминов

Сайт-витрина с полноценным магазинным функционалом, собранный на базе данных
скрапера (`vitaminy.db`). Стек: **Next.js 16 (App Router) + TypeScript +
Tailwind CSS v4**, иконки — **Lucide**.

## Возможности

- Главная с hero-каруселью, категориями, «Новинками» и преимуществами.
- Каталог категорий / пищевых добавок / брендов.
- Страница категории с фильтрами по бренду и цене, сортировкой и пагинацией.
- Карточка товара: галерея, характеристики, применение, состав, дисклеймер.
- Поиск по названию, бренду и описанию.
- Корзина с оформлением заказа, избранное, сравнение (до 4 товаров).
- Фиксированный хедер с десктопной навигацией и мобильным выдвижным меню.
- Полная адаптивность (Mobile First), AVIF-изображения, семантика и ARIA.

## Быстрый старт

```bash
npm install
npm run dev          # http://localhost:3000
```

Продакшн-сборка:

```bash
npm run build
npm start
```

## Перегенерация данных

Данные лежат в `data/*.json`, изображения — в `public/images/*`. Они
генерируются из SQLite-базы скрапера (находится в `../scraper/data/vitaminy.db`):

```bash
npm run data
```

Скрипт `scripts/export-data.mjs`:
- читает БД (встроенный `node:sqlite`, Node ≥ 22.5);
- чистит «мусор» в описаниях, разбирает характеристики в пары «ключ — значение»;
- определяет бренд товара по категориям-брендам;
- копирует `.avif`-изображения в `public/images/`;
- **умножает цены** на стабильный случайный множитель **2.1–2.85** для каждого
  товара (множитель детерминирован по id, поэтому цены не «прыгают» между
  запусками; отключить — `PRICE_MULTIPLY=0`).

## Скрапер и ежедневное обновление

`scraper/` — парсер **www.vitaminy.kg** (Python, aiohttp + BeautifulSoup).
Собирает категории, карточки товаров (название, описание, характеристики,
применение, состав, дисклеймер, цены, артикул) и скачивает картинки в
`data/images/`. Всё хранится в SQLite `scraper/data/vitaminy.db`.

```bash
cd scraper
python3 -m venv venv && venv/bin/pip install -r requirements.txt
./venv/bin/python scraper.py                 # полный (инкрементальный) парсинг
./venv/bin/python check_scraper.py --ids 1286,2429   # проверка парсинга полей
```

Ежедневный пайплайн запускается скриптом `update_site.sh`:
парсинг → экспорт с умножением цен → `npm run build` → перезапуск сервера.
Пример записи в `crontab` (каждый день в 5:00):

```
0 5 * * * /home/bbx/Work/DS_ws/update_site.sh >> /home/bbx/Work/DS_ws/logs/cron.log 2>&1
```

## Структура

```
src/
  app/              # маршруты (App Router)
    catalog/[slug]    # категория или обзор вкладки
    product/[id]      # карточка товара
    cart, favorites, compare, search, brands, ...
  components/       # Header, Footer, Hero, ProductCard, CatalogView и др.
  lib/
    data.ts         # чтение JSON + типы + выборки
    store.tsx       # корзина / избранное / сравнение (Context + localStorage)
    nav.ts          # дерево навигации
    categories.ts   # работа с категориями
    format.ts       # форматирование цен, плюрализация
```

## Примечания

- Бренд товара определяется по категории вкладки «Бренды»; если её нет —
  показывается производитель из названия.
- Шрифт **Heuristica** (декоративные выделения) недоступен в открытых
  источниках — используется засечковый fallback (Georgia).
- Корзина/избранное/сравнение хранятся в `localStorage` браузера.

## Уведомления о заказах в Telegram

При оформлении заказа заявка отправляется в Telegram-бот. Токен и `chat_id`
задаются в `.env.local`:

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Чтобы получать уведомления, владельцу нужно один раз запустить бота
(нажать `/start` в Telegram) — иначе API вернёт `chat not found`
(Telegram запрещает ботам писать пользователям первыми).
